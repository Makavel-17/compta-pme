# Compta PME

Application pédagogique de comptabilité en partie double, plan comptable suisse, pour l'École de commerce Aimée-Stitelmann (Genève).

Fonctionne entièrement dans le navigateur : aucune donnée d'élève n'est envoyée en ligne.

## Développement

```bash
npm install
npm run dev     # serveur local
npm test        # tests du moteur comptable
npm run build   # site statique dans dist/
```

Les règles du projet sont décrites dans [CLAUDE.md](CLAUDE.md).
